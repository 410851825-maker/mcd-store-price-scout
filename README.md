# 麦门门店价差官 · mcd-store-price-scout

> **我常去的那家店，95 个商品只有 1 个打折。**
>
> 基于 **麦当劳中国 MCP（McDonald's China MCP）** 开发的门店定价洞察 Skill：
> 把「这家店到底值不值得吃」的判断，从感觉变成可复核的结论。
>
> 又名：麦门店店比价官 / 麦门定价侦探 / MCD Store Price Scout。

## 项目介绍

**你站在麦当劳门口，想买巨无霸。这家店多少钱？换个店呢？手里那张券在这能用吗？**

「麦门门店价差官」会拉取你附近门店的**真实菜单、真实活动折扣、真实可兑券**，
加上你自己的**历史消费画像**，给出一张能直接照着做的购买决策卡。

它回答的不只是"哪边便宜"，而是四个问题合起来的结论：

| 问题 | 数据来源 | 确定性 |
|---|---|---|
| **这家店的定价正常吗？** | 逐店 `query-meals` 比对 `originalPrice` vs `currentPrice` | 确定性核对 |
| **同款别家多少钱？** | 逐店 `query-meals` 跨店比价 | 确定性核对 |
| **我的券在这儿能省多少？** | `query-store-coupons` + `calculate-price` 实测算价 | 确定性核对 |
| **我平时爱吃什么？** | `order-list` 复购画像 | 确定性核对 |

**没有一处是大模型估算的**——每个数字都来自麦当劳 MCP 的真实返回。

## 为什么做这个：三个实测发现

### 发现一：同产品跨门店价格**不一致**，极差可达 ¥27

实测 18 家门店（佛山禅城 5 家 + 广州海珠/南站 5 家 + 佛山九江 3 家等）：

| 商品 | 最低价 | 最高价 | 极差 | 极差率 |
|---|---:|---:|---:|---:|
| 龙焰鸡腿堡三件套 | ¥26.9 | ¥53.0 | **¥27.1** | **100.7%** |
| 龙焰芝士棒鸡腿堡三件套 | ¥29.9 | ¥57.0 | **¥27.1** | **90.6%** |
| BFF四宫格小食盘 | ¥39.8 | ¥61.5 | ¥21.7 | 54.5% |
| "苹"水相"鱼"套餐 | ¥36.0 | ¥55.5 | ¥19.5 | 54.2% |
| 板烧鸡腿堡三件套 | ¥34.5 | ¥52.5 | ¥18.0 | 52.2% |
| 浓浓黑巧 | ¥13.9 | ¥25.0 | ¥11.1 | 79.9% |

**同一份套餐，在社区店 ¥29.9，在交通枢纽 ¥57.0——差 90.6%。**

### 发现二：门店折扣覆盖率存在**结构性断层**

| 门店类型 | 代表门店 | 有折扣商品占比 |
|---|---|---:|
| 社区店 | 佛山福源大厦 | **51.2%**（62/121） |
| 社区店 | 佛山岭南天地 | 48.0%（61/127） |
| 社区店 | 佛山九江 | 47.1%（56/119） |
| 社区店 | 广州客村 | 48.4%（59/122） |
| 景区/商场 | 佛山城门头路快捷小站 | 39.3%（11/28） |
| **地标门店** | **广州塔餐厅** | **1.1%**（1/95） |
| **交通枢纽** | **广州南站 B11** | **0%**（0/83） |
| **交通枢纽** | **广州南站 3F** | **0%**（0/81） |

**16 家社区店折扣覆盖稳定在 46–51%，而 3 家地标/枢纽店是 0–1%。**
这不是个别门店的运气，是**定价体系不同**——枢纽店连原价都定得更高
（实测 83 项共同商品中，60 项连 `originalPrice` 都不同）。

### 发现三：券的适用范围有**多层约束**，还有「套餐陷阱」

一张「13.9 浓浓黑巧」券的可用性，实测涉及 **13 个维度**：
有效期、领取天数、星期、时段、到店/外送、得来速/团餐、渠道（限 4 个）、
是否预付、是否免单、支付方式、可否赠送、能否预约、库存。

而且有两个反直觉的事实：

1. **券只认「单独点」，不认套餐。**
   实测：巨无霸三件套 + 券 → `discount=0`，券完全不生效。
   尽管套餐的「选择套餐内饮料」里明明有「热浓浓黑巧中杯」。

2. **券声明的 productCode 常常在菜单里不存在。**
   券指向 `9900016270`，而菜单里实际是 `515946`。
   用券给的编码直接算价会**静默返回 price=0**（不报错）——必须先展开。

**这两个坑麦当劳 App 不会提示，官方文档也没写。** 本工具把它们变成了明确的结论。

## 安装方法

**零第三方依赖**，Python 3.9+ 标准库即可。

```bash
git clone https://github.com/<你的账号>/mcd-store-price-scout.git
cd mcd-store-price-scout
```

### 申请 MCP Token

1. 打开 <https://open.mcd.cn/mcp>
2. 右上角【登录】→ 手机号验证
3. 登录后右上角变【控制台】→ 点开弹窗
4. 点【激活】→ 申请 MCP Token
5. 阅读并同意服务协议
6. Token 生成后一键复制

### 配置环境变量

```bash
# PowerShell
$env:MCD_MCP_TOKEN = "你的Token"

# Bash / macOS / Linux
export MCD_MCP_TOKEN="你的Token"
```

### 在 WorkBuddy / Claude Code / Cursor 中接入

编辑 MCP 配置（WorkBuddy：`C:\Users\<你>\.workbuddy\mcp.json`）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> 也可以直接用仓库里的 `mcp-config.example.json`，把 `${MCD_MCP_TOKEN}` 换成实际 Token。

## 使用示例

### 命令行

```bash
# 基本用法：查某个区域的门店
python scripts/price_scout.py --city 佛山 --keyword 禅城区

# 盯一个具体产品

# 跨片区对比（找定价体系差异）

    --compare 广州/广州塔 --compare 广州/南站 --compare 佛山/禅城区

python scripts/price_scout.py --city 佛山 --keyword 禅城区 --json result.json

python scripts/sample_runner.py
```

## 技术实现

### 架构：取数交给 MCP，算术交给代码，表达交给 Agent

```
用户提问「我要买巨无霸」
        │
        ├─ query-nearby-stores ──→ 附近门店列表（storeCode）
        │
        ├─ query-meals × N 店 ──→ 每店菜单 + 原价/现价
        │                          └─ 折扣覆盖率、跨店价差
        │
        ├─ query-store-coupons × N 店 ──→ 券的 products + 门店可用性
        │        └─ query-meal-detail 展开券的虚拟编码
        │        └─ calculate-price 实测算价验算 discount
        │
        └─ order-list ──→ 历史复购画像
                    │
                    ▼
            购买决策卡（确定性结论）
```

**关键设计：算术一律交给代码，不让模型口算价格。**
`calculate-price` 返回的是「分」，直接用会导致 100 倍误差——这类错误模型无法自检。

### 处理过的三个真实数据坑

| 坑 | 现象 | 处理 |
|---|---|---|
| **虚拟编码错位** | 券声明 `9900016270`，菜单实际 `515946`；用前者算价静默返回 price=0 | 先经 `query-meal-detail` 展开 rounds 拿到真实编码再算价 |
| **套餐陷阱** | 券在套餐内 `discount=0`，但套餐明明含该商品 | 对每个候选套餐实测算价比对 discount，不靠字段推断 |
| **静默零值** | `calculate-price` 的商品字段名是 `productCode`（传 `code` 静默返回全 0） | 统一封装在 `mcd_client.calculate_price()`，并有自测覆盖 |

> 全部细节见 [`references/mcp-tools.md`](references/mcp-tools.md)。

## 数据与隐私

- 本工具读取的 `query-my-*` / `order-list` 全部是**当前登录用户自己的**私有数据
- 仓库中**不含任何真实 Token、手机号、账户 ID、订单号**
- `sample_data/sample_data.json` 是**完全脱敏**的样例：门店名、商品名、券 ID 全部替换为示例值
- Token 只从环境变量 `MCD_MCP_TOKEN` 读取，代码与配置文件中均无明文
- 本工具**只做只读查询**，不下单、不领券、不抽奖、不改地址
